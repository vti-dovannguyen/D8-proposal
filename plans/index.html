Số function của mỗi gói được tính trực tiếp từ ma trận chức năng.

Danh mục toàn bộ chức năng của hệ thống, phân theo Module / Sub-module, mỗi function gắn một Action (View / Create / Edit / Delete).

Ba gói có quan hệ bao hàm tăng dần: BASIC ⊂ STANDARD ⊂ OPTION. Chỉnh giá và mô tả tại đây; phạm vi function chỉnh ở màn "Gán Function theo Plan".

💡 Module Intelligence Drone (13 function nội bộ: quản lý khách hàng, báo cáo, log, cài đặt) không thuộc gói nào — chỉ nhà cung cấp truy cập.
